# مغامرة البرمجة (Osmo Coding Adventure)

منصة ألعاب تعليمية عربية لطفل في الخامسة، تعمل بقطع Osmo Coding المادية أمام الآيباد مع عاكس Osmo. PWA تعمل على Safari دون App Store ودون إنترنت بعد التحميل الأول.

## التشغيل محليًا
```bash
npm test          # اختبارات الوحدات (node:test)
npm run serve     # http://localhost:8080
npm run smoke     # اختبار متصفح بكاميرا وهمية (يحتاج playwright)
```
لا توجد اعتمادات تشغيل. أدوات التطوير (playwright, sharp) اختيارية.

## التشغيل على الآيباد
الكاميرا في Safari تتطلب **HTTPS**. الطريقة الموصى بها: GitHub Pages (مجاني، HTTPS تلقائي). راجع `docs/TESTING.md` لخطوات الاختبار وما يجب إرساله.

## البنية
```
src/vision/      محرك الرؤية — وحدات صرفة بلا DOM (geometry, rectify, quality, adaptive)
src/calibration/ تخزين المعايرة لكل جهاز/اتجاه
src/platform/    الكاميرا والاتجاه (واجهات المتصفح)
src/app.js       صفحة المعايرة (ربط فقط)
sw.js            العمل دون إنترنت
tests/           اختبارات الوحدات
tools/           خادم محلي، اختبار دخان، توليد الأيقونات
docs/            الجدوى، القرارات، الاختبارات، المهام
```
محرك الرؤية مفصول عن الواجهة ليُعاد استخدامه في ألعاب لاحقة.

## الخصوصية
كل المعالجة داخل الجهاز. لا إرسال صور، لا تسجيل فيديو، لا حسابات، لا تتبع. اللقطات تُحفظ فقط بعد موافقة صريحة.
