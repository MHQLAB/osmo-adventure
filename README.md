# مغامرة البرمجة (Osmo Coding Adventure)

منصة ألعاب تعليمية عربية لطفل في الخامسة، تعمل بقطع Osmo Coding المادية أمام الآيباد مع عاكس Osmo. PWA تعمل على Safari دون App Store ودون إنترنت بعد التحميل الأول.

## التشغيل محليًا
```bash
npm test          # اختبارات الوحدات (node:test)
npm run serve     # http://localhost:8080
npm run smoke     # اختبار متصفح بكاميرا وهمية (يحتاج playwright)
```
لا توجد اعتمادات تشغيل. أدوات التطوير (playwright, sharp) اختيارية.

## التشغيل على الآيباد
الرابط: `https://mhqlab.github.io/osmo-adventure/` (بعد تفعيل النشر). الكاميرا تتطلب HTTPS.
راجع `docs/TESTING.md` لخطوات الاختبار وما يجب إرساله.

## النشر والتحديث
- كل `push` إلى `main` يشغّل GitHub Actions: فحص المستودع ← الاختبارات ← بناء `_site` (قائمة بيضاء) ← النشر على Pages.
- رقم الإصدار يُختم تلقائيًا في `sw.js` فيُستبدل مخزن الملفات القديم فقط.
- **التقدم والمعايرة لا يُمسّان عند التحديث**: محفوظة في localStorage/IndexedDB بمفاتيح `osmo.*`، وأي تغيير في صيغتها يتطلب ترحيلًا لا حذفًا.
- نسخة احتياطية: «التشخيص» ← «نسخة احتياطية للإعدادات» / «استيراد» (نص JSON بلا صور) — للانتقال بين الأجهزة.
- تنبيه: بيانات Safari وبيانات التطبيق المثبت على الشاشة الرئيسية **منفصلة** في iPadOS. اعتمد التطبيق المثبت للعب، وانقل المعايرة بالنسخة الاحتياطية إن لزم.

## حماية المستودع (عام)
`tools/check-repo.js` يرفض أي صورة غير الأيقونات، ومسارات العينات، وملفات الأسرار، والنصوص الشبيهة بالمفاتيح. يعمل قبل كل commit محليًا وفي CI قبل النشر. اللقطات تُحفظ على الآيباد فقط ولا مكان لها في المستودع.

## البنية
```
src/vision/      محرك الرؤية — وحدات صرفة بلا DOM (geometry, rectify, quality, adaptive)
src/calibration/ تخزين المعايرة لكل جهاز/اتجاه
src/platform/    الكاميرا والاتجاه (واجهات المتصفح)
src/app.js       صفحة المعايرة (ربط فقط)
sw.js            العمل دون إنترنت
tests/           اختبارات الوحدات
tools/           خادم محلي، اختبار دخان، توليد الأيقونات
docs/            الجدوى، القرارات، الاختبارات، المهام
```
محرك الرؤية مفصول عن الواجهة ليُعاد استخدامه في ألعاب لاحقة.

## الخصوصية
كل المعالجة داخل الجهاز. لا إرسال صور، لا تسجيل فيديو، لا حسابات، لا تتبع. اللقطات تُحفظ فقط بعد موافقة صريحة.
