# الانتقال إلى osmo.mohammedhq.com (غير مفعّل — بانتظار طلب المستخدم)

## الجاهزية الحالية
- كل المسارات نسبية (`./`) في index.html وmanifest وsw.js، ومختبرة آليًا (`tests/portability.test.js`).
- يعمل التطبيق تحت `https://mhqlab.github.io/osmo-adventure/` وعلى جذر النطاق الفرعي دون تعديل كود.
- لا يوجد ملف CNAME عمدًا.

## ما يتغير فعليًا عند الانتقال
التخزين المحلي، وعامل الخدمة، وإذن الكاميرا، والتطبيق المثبت كلها مرتبطة بالنطاق. النطاق الجديد = تطبيق جديد ببيانات فارغة.

## الخطوات (عند الطلب)
1. **قبل أي تغيير** على كل آيباد: افتح التطبيق المثبت ← التشخيص ← «حفظ ملف نسخة احتياطية» (تحفظ المعايرة، ولاحقًا التقدم).
2. DNS عند مزوّد mohammedhq.com: سجل `CNAME` باسم `osmo` يشير إلى `mhqlab.github.io`.
3. GitHub ← Settings ← Pages ← Custom domain: `osmo.mohammedhq.com`، ثم تفعيل Enforce HTTPS بعد إصدار الشهادة.
   (مع النشر عبر Actions لا يلزم ملف CNAME في المستودع.)
4. على الآيباد: افتح `https://osmo.mohammedhq.com` في Safari ← أضفه للشاشة الرئيسية ← افتحه ← «فتح ملف نسخة احتياطية».
5. احذف الأيقونة القديمة بعد التأكد من سلامة البيانات.
6. الرابط القديم على github.io يحوّله GitHub تلقائيًا للنطاق الجديد.

## مخاطر
- نسيان الخطوة 1 = فقدان المعايرة والتقدم على ذلك الجهاز.
- المعايرة قد تحتاج تحققًا بعد النقل (التدوير قد يختلف بين Safari والتطبيق المثبت).
