# دراسة الجدوى — المرحلة صفر

تاريخ: 2026-11-26. مستوى الثقة موضح لكل بند.

## 1. بيئة التطوير (مؤكد)
- Node 22، TypeScript 6، Playwright/Chromium، sharp، Git. لا وصول للشبكة لتثبيت حزم npm.
- لا يوجد Vite/Phaser/OpenCV.js محليًا. القرار: **بلا أدوات بناء** (ES Modules أصلية) — تعمل مباشرة على Safari.

## 2. قطع Osmo Coding

**الصورة المرفقة لم تصل** (المرفق الوحيد ملف نص). الحصر أدناه من وثائق Osmo الرسمية ويحتاج مطابقة بالصورة.

- في المجموعة الحديثة: **لا توجد قطعة Play/Caution**؛ يُشغَّل البرنامج بلمس الشاشة. الأرقام تبدأ من 2 (توافق وصفك «2 إلى 5»).

**قرار:** نحافظ على المعاني الأصلية (Walk/Jump/Hand/Repeat/Rest/Subroutine/Magic) حتى لا يختلط الأمر على الطفل.

## 3. Osmo SDK (مرجّح)
- أعلنت Tangible Play عن برنامج مطورين وSDK في مرحلة ألفا (iOS، مع خطط لـUnity/Android). لم أجد SDK عامًا متاحًا للتنزيل ولا ترخيصًا منشورًا، ولا شيء للويب.
- **القرار:** محرك رؤية مستقل. نعيد التقييم إذا ظهر SDK عام.

## 4. Safari / iPadOS (مؤكد من تقارير WebKit)
- getUserMedia يتطلب HTTPS. يعمل في Safari، وفي تطبيقات الشاشة الرئيسية منذ iOS 13.4 تقريبًا، **مع أخطاء معروفة**:
  - **iPadOS 26: صورة الكاميرا تدور 90° في التطبيق المثبت على الشاشة الرئيسية** (WebKit bug 299591). ← السبب الذي جعل التدوير اليدوي محفوظًا لكل اتجاه، ونتيجة مختلفة متوقعة بين Safari والتطبيق المثبت.
  - تغيير الـhash/المسار في التطبيق المثبت قد يوقف الكاميرا ويعيد طلب الإذن ← **التطبيق صفحة واحدة بلا توجيه بالـhash**.
  - فتح مركز التحكم قد يجمّد البث في الوضع المثبت ← يلزم زر «استئناف».
- منذ iOS/iPadOS 26 أي موقع يُضاف للشاشة الرئيسية يفتح كتطبيق ويب. Service Worker مدعوم للعمل دون إنترنت.
- **لم يُختبر شيء من هذا على آيبادك بعد.**

## 5. البنية المختارة
| تقنية | القرار | السبب |
|---|---|---|
| JS (ES Modules) بلا بناء | ✅ | يعمل مباشرة، صيانة أسهل، لا اعتماد على npm |
| TypeScript | لاحقًا (JSDoc الآن) | يحتاج بناء؛ يُضاف عند نمو الكود |
| React / Vite | ❌ حاليًا | لا حاجة لصفحة معايرة؛ يعاد التقييم مع واجهة اللعبة |
| Phaser | مرشح للمرحلة 4 | محرك ألعاب 2D ناضج، MIT |
| OpenCV.js / WASM | مؤجل | ~8MB؛ نستخدم معالجة JS خفيفة أولًا ونقيس |
| TensorFlow.js | مؤجل | فقط إذا فشل التصنيف التقليدي في بلوغ الدقة |
| IndexedDB | للتقدم والعينات لاحقًا | المعايرة الآن في localStorage (صغيرة) |
| PWA | ✅ | تثبيت دون App Store وعمل دون إنترنت |

**شرط الانتقال لتطبيق أصلي (Swift/Vision):** فشل الكاميرا في التطبيق المثبت بشكل غير قابل للالتفاف، أو أداء غير كافٍ بعد القياس. التكلفة: Mac + Xcode، وإعادة تثبيت كل 7 أيام بحساب مجاني أو 99$/سنة لحساب مطور.

## 6. المخاطر الرئيسية
1. العاكس قد لا يناسب أحد جهازيك ماديًا (يُختبر).
2. دقة 98% غير مضمونة بمعالجة تقليدية؛ قد نحتاج نموذجًا صغيرًا مدرَّبًا على عيناتك.
3. أخطاء WebKit في وضع التطبيق المثبت؛ الخطة البديلة: التشغيل من Safari مباشرة.
4. الصوت العربي دون إنترنت: أصوات iPadOS المحلية تحتاج اختبارًا؛ البديل ملفات مسجلة.
